Here's a flowchart illustrating the Binary Exponentiation Algorithm:

1. Start with result = 1, base = a, and exp = b.
2. While exp > 0:
        If the current bit of exp is 1, update result = result × base.
        Square base (base = base × base).
        Right shift exp (exp = exp >> 1).
3. When exp == 0, return result.
